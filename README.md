# defi-research

Onderzoekslaag voor DeFi en blockchain, met een Claude-agent die leert van feedback.
Alleen onderzoek: geen wallets, geen transacties. Uitvoering komt later in een aparte repo op
een andere machine (zie `plans/roadmap.md`).

- `CLAUDE.md` — protocol en harde grenzen
- `profiel.md` · `lessen.md` · `MEMORY.md` — wat de agent over mij en van mij leert
- `plans/ORACLE.md` — ideeën · `plans/roadmap.md` — fasen
- `intel/sources/` — geverifieerde bronnen · `analyses/` — analyses
- `tests/test_context_budget.py` — bewaakt geheugengroei
- `playbooks/plan_interview.md` — zwaar plan-spoor (uit `claude-config`)
